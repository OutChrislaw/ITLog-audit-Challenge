# ITLog Audit Challenge

## Project Description

This project is a modern, responsive web application designed for IT log auditing and user management. It demonstrates best practices in HTML, CSS, and project organization, with a focus on accessibility, maintainability, and user experience.

## Features

- Semantic HTML structure (header, main, section, footer)
- Responsive layout using Flexbox and Grid
- Accessible and well-labeled forms for login and signup
- Clean, consistent file and folder naming
- Centralized assets folder for images
- Modern, user-friendly design
